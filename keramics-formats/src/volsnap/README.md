# volsnap

The volsnap module provides read-only support for the
[Volume Shadow Snapshot (volsnap)](https://keramics.github.io/volsnap.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| | On-disk (or in-volume) shadow storage |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| | Redirected shadow storage |
