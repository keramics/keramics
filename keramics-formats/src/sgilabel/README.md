# sgilabel

The sgilabel module provides read-only support for the
[SGI disklabel (sgilabel)](https://keramics.github.io/sgilabel.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Byte order | Big-endian |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| | Volume directory files |
