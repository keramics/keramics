# ext

The ext module provides read-only support for the
[Extended File System (ext)](https://keramics.github.io/ext.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format version | 2 (ext2), 3 (ext3), 4 (ext4) |
| Compression | zlib |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| Format version | 1 |
| | Compression |
| | Encryption |
