# sparsebundle

The sparsebundle module provides read-only support for the
[Mac OS sparse bundle (.sparsebundle)](https://keramics.github.io/sparsebundle.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Encryption | [Mac OS encrypted encoding](https://github.com/keramics/keramics/tree/main/keramics-formats/src/cdsaencr/README.md) |
