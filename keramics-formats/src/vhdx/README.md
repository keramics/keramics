# vhdx

The vhdx module provides read-only support for the
[Virtual Hard Disk version 2 (VHDX) image format](https://keramics.github.io/vhdx.html)

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format versions | 2.1 |
| Image types | Differential (or differencing), Dynamic-size (or sparse), Fixed-size |
