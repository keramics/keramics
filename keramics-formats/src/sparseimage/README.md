# sparseimage

The sparseimage module provides read-only support for the
[Mac OS sparse image (.sparseimage)](https://keramics.github.io/sparseimage.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Encryption | [Mac OS encrypted encoding](https://github.com/keramics/keramics/tree/main/keramics-formats/src/cdsaencr/README.md) |
