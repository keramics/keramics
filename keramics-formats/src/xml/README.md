# xml

The xml module provides read-only support for Extensible Markup Language (XML) documents.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Elements | Start tags, End tags, Empty-element tags, Nested elements, Attributes, Character data |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| | CDATA sections, Comments inside element content, Entity and character references, Processing instructions |
