# cpio

The cpio module provides read-only support for the
[Copy in and out (CPIO) archive format](https://keramics.github.io/cpio.html).

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format variants | Binary (big-endian and little-endian), New ASCII (newc and CRC), Portable ASCII (odc) |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| | Directory hierarchy reconstruction |
