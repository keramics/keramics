# vhd

The vhd module provides read-only support for the
[Virtual Hard Disk (VHD) image format](https://keramics.github.io/vhd.html).

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format versions | 1.0 |
| Image types | Differential (or differencing), Dynamic-size (or sparse), Fixed-size |
