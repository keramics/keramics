# splitraw

The splitraw module provides read-only support for split (or segmented) RAW storage media images.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Segment naming schemas | Alphabetic (for example, imageaa), Numeric (for example, image.1, image.001, image_001), "X of N" (for example, image.1of5) |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| | Variable segment sizes (other than the last segment) |
