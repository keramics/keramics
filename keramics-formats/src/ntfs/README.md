# ntfs

The ntfs module provides read-only support for the
[New Technologies File System (NTFS)](https://keramics.github.io/ntfs.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format versions | 3.0, 3.1 |
| Compression | LZNT1, Windows Overlay Filter (WOF) (LZX and LZXPRESS-Huffman) |
| | Case sensitive directories |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| Format versions | 1.0, 1.1, 1.2 |
| | Encrypted File System (EFS) |
