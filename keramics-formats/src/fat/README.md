# fat

The fat module provides read-only support for the
[File Allocation Table (FAT)](https://keramics.github.io/fat.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format variants | FAT12, FAT16, FAT32 |
| Names | Short (8.3) names, VFAT long names |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| Encodings | Configurable non-ASCII codepages for short names |
