# bsdlabel

The bsdlabel module provides read-only support for the
[BSD disklabel (bsdlabel)](https://keramics.github.io/bsdlabel.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Byte order | Little-endian |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| Byte order | Big-endian |
