# pdi

The pdi module provides read-only support for the
[Parallels Disk Image (PDI)](https://keramics.github.io/pdi.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format versions | 2 |
| Image types | Differential (or differencing), Dynamic-size (or expanding), Fixed-size (or plain), Split |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| Format versions | 1 |
