# plist

The plist module provides read-only support for the
[Property list (plist)](https://keramics.github.io/plist.html) format.

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format variants | XML property list (plist) |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| Format variants | Binary property list (bplist), OpenStep (ASCII) property list |
