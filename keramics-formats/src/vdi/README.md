# vdi

The vdi module provides read-only support for the
[Virtual Disk Image (VDI) format](https://keramics.github.io/vdi.html).

Supported features:

| Category | Feature(s) |
| --- | --- |
| Format versions | 1.1 |

Unsupported features:

| Category | Feature(s) |
| --- | --- |
| Image types | Differential (or differencing) |
| | Snapshots |
