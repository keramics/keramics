# keramics-formats

Data formats for Keramics.

[docs.rs](https://docs.rs/keramics_formats)

Supported data formats:

* [Apple File System (APFS)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/apfs/README.md)
* [Apple File System Compression (decmpfs)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/decmpfs/README.md)
* [Apple Partition Map (APM)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/apm/README.md)
* [BitLocker Drive Encryption (BDE)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/bde/README.md)
* [BSD disklabel (bsdlabel)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/bsdlabel/README.md)
* [Copy in and out (CPIO) archive format](https://github.com/keramics/keramics/tree/main/keramics-formats/src/cpio/README.md)
* [Expert Witness Compression Format (EWF)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/ewf/README.md)
* [Extended File System (ext)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/ext/README.md)
* [Extensible File Allocation Table (exFAT)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/exfat/README.md)
* [Extensible Markup Language (XML)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/xml/README.md)
* [File Allocation Table (FAT) file system](https://github.com/keramics/keramics/tree/main/keramics-formats/src/fat/README.md)
* [GUID Partition Table (GPT)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/gpt/README.md)
* [Hierarchical File System (HFS)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/hfs/README.md)
* [Linux Logical Volume Manager (LVM)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/linuxlvm/README.md)
* [Linux Unified Key Setup (LUKS) Disk Encryption](https://github.com/keramics/keramics/tree/main/keramics-formats/src/luksde/README.md)
* [Mac OS encrypted encoding (cdsaencr)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/cdsaencr/README.md)
* [Mac OS sparse bundle (.sparsebundle)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/sparsebundle/README.md)
* [Mac OS sparse image (.sparseimage)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/sparseimage/README.md)
* [Master Boot Record (MBR)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/mbr/README.md)
* [New Technologies File System (NTFS)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/ntfs/README.md)
* [Parallels Disk Image (PDI)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/pdi/README.md)
* [Property list (plist)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/plist/README.md)
* [QEMU Copy-On-Write (QCOW) image file](https://github.com/keramics/keramics/tree/main/keramics-formats/src/qcow/README.md)
* [SGI disklabel (sgilabel)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/sgilabel/README.md)
* [Split (or segmented) RAW storage media image](https://github.com/keramics/keramics/tree/main/keramics-formats/src/splitraw/README.md)
* [Universal Disk Image Format (UDIF)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/udif/README.md)
* [Virtual Disk Image (VDI)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/vdi/README.md)
* [Virtual Hard Disk (VHD) image](https://github.com/keramics/keramics/tree/main/keramics-formats/src/vhd/README.md)
* [Virtual Hard Disk version 2 (VHDX) image](https://github.com/keramics/keramics/tree/main/keramics-formats/src/vhdx/README.md)
* [VMWare Virtual Disk Format (VMDK)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/vmdk/README.md)
* [Volume Shadow Snapshot (volsnap)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/volsnap/README.md)
* [X File System (XFS)](https://github.com/keramics/keramics/tree/main/keramics-formats/src/xfs/README.md)
